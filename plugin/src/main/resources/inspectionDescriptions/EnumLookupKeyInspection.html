Highlights duplicate or null values supplied to enum constants for keys marked @KeyField(strictKeys = true) or @KeyField(strictNullKeys = true).

Resolution traces each constant's constructor arguments back to the annotated field via the constructor body's this.<field> = <param> assignments. Literal arguments and references to static final constants are resolved; non-resolvable expressions are skipped to avoid false positives.

Both severities default to ERROR and are independently configurable in the inspection options panel.

This is a pure IDE-time check - the annotation processor never injects runtime validation, so toggling these flags has no effect on the generated bytecode.
