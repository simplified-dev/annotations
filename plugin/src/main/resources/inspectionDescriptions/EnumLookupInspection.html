Flags misuse of @EnumLookup and its companion @KeyField:
  • @EnumLookup on a non-enum type - the processor cannot generate cached lookups for anything but an enum.
  • @KeyField on a static field - keys must live on instance state so each enum constant carries its own value.
  • @KeyField on a field whose enclosing type lacks @EnumLookup - the annotation is silently ignored at processing time; this warning surfaces it early.
  • @KeyField(strictNullKeys = true) on a primitive-typed field - primitives cannot be null, so the attribute has no effect.
  • @KeyField(methodName = ...) whose value is not a valid Java identifier or doesn't start with an uppercase letter - the generated of<Name> / findBy<Name> methods would be unreadable or fail to compile.
  • Two @KeyField annotations producing colliding generated method signatures - one of them must set methodName to disambiguate.

This inspection covers annotation-misuse errors only. Strict-key value validation (duplicate / null values across constants) lives in the separate @KeyField duplicate / null key inspection.
