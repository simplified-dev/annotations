Reports the entry points a @ClassBuilder skips because the builder the target declares has no constructor they can call.

A declared builder is merged into: the generated members are appended beside the author's, and the author's constructors are the builder's constructors. Every entry point creates the builder with the @BuilderSeed parameters, in order, so where the declared builder declares constructors and none taking the seeds' types in that order, builder(), from(T) and mutate() are not generated - and neither are they where every constructor taking them declares a throws clause naming an exception not known to be unchecked, since the entry points call it with nothing around the call to handle what it throws. Neither the processor nor the editor resolves a thrown name, so only RuntimeException, Error and their common subclasses in java.lang and java.util, written by simple or qualified name, count as unchecked; any other name is treated as checked, an unchecked exception of the author's own among them. The processor says so in a compiler note and completion leaves the three out; this warning is the note, in the same words, on the annotation.

On a class or record target, and on a concrete link of a SuperBuilder chain, the entry points pass nothing, so the constructor they need is a no-argument one. A builder that declares no constructor at all keeps its implicit default, which serves them. On a constructor or static factory target the one entry point is builder(..), and it needs a constructor taking exactly the seeds - their types in parameter order, compared by erasure and simple name, so a constructor of the seed count taking other types, or the seeds swapped, does not serve. A static factory inside an interface is such a target, and its builder is the class the interface body declares.

Either declare that constructor, or write the entry points by hand. An entry point named NONE through @BuilderNames is not generated, so it is not reported as skipped.

Nothing is reported on an interface type target, whose entry points create its sibling builder; on an abstract target, which has no entry points of its own; on an annotated member the processor refuses, such as an instance method or one beside an annotated type, which merges nothing; or beside a declared shape the merge refuses, which the declared-builder shape inspection reports as an error.
